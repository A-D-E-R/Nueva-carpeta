SUBIR EL PROYECTO A GITHUB

1. Entra a GitHub y abre el repositorio que creó la profesora o crea uno nuevo si ella lo indicó.
2. Pulsa Add file > Upload files.
3. Descomprime Farmasleyd_GitHub.zip en tu computadora.
4. Selecciona los archivos de la carpeta (index.html, README.md, Manual_de_Calidad.pdf y RECIBO.pdf).
5. Espera a que terminen de cargarse y pulsa Commit changes.

IMPORTANTE:
- Si la profesora exige conservar el nombre original del HTML, puedes renombrar index.html a farmaleyd_2026.html antes de subirlo.
- El video no se incluyó porque no se adjuntó un archivo de video en este chat.
- Revisa con la docente si el recibo debe ser una muestra o si ella proporcionará uno real.
