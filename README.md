# FARMASLEYD 2026 — Farmacia y Bienestar

## 1. Información general del proyecto

**Farmasleyd 2026** es un proyecto académico de una tienda virtual de farmacia. Su propósito es presentar productos de farmacia y bienestar mediante una página web con catálogo, promociones, información para los visitantes y un proceso de compra demostrativo.

La página está desarrollada principalmente en un archivo HTML que integra la estructura, los estilos y las funciones JavaScript del sitio.

## 2. Objetivo del proyecto

Crear una página web de farmacia que permita al visitante explorar productos, consultar información, utilizar herramientas de búsqueda y filtros, agregar artículos a un carrito y generar un recibo digital de demostración.

## 3. Características principales de la página

- **Pantalla de inicio de sesión demostrativa:** solicita nombre y contraseña antes de entrar al sitio. No utiliza autenticación mediante servidor.
- **Diseño visual adaptable:** contiene estilos para organizar el contenido en diferentes tamaños de pantalla.
- **Navegación por secciones:** permite recorrer las distintas áreas de la tienda.
- **Carrusel de ofertas:** presenta promociones destacadas y permite cambiar entre diapositivas.
- **Catálogo de productos:** muestra artículos de farmacia y bienestar.
- **Categorías y filtros:** permite organizar y filtrar productos por categoría.
- **Buscador:** facilita localizar productos dentro del catálogo.
- **Carrito de compras:** permite agregar productos, modificar cantidades y actualizar los importes.
- **Cupones y cálculo de compra:** incluye una función para aplicar cupones y calcular los importes correspondientes.
- **Proceso de compra demostrativo:** solicita información para preparar el pedido.
- **Recibo digital:** presenta un resumen de la compra con los productos y el total.
- **Información sobre anticonceptivos:** incluye una sección informativa relacionada con estos productos.
- **Información sobre suplementos:** presenta contenido sobre productos como proteínas, calcio y otros suplementos.
- **Videos y promociones:** incorpora espacios o enlaces para contenido audiovisual.
- **Sucursales y contacto:** contiene información para orientar al visitante.

> **Nota:** las funciones descritas corresponden a elementos identificados en el código HTML entregado. El funcionamiento de recursos externos depende de la conexión a Internet.

## 5. Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS:** presentación visual y estilos personalizados.
- **Tailwind CSS:** biblioteca de estilos cargada mediante CDN.
- **JavaScript:** funciones interactivas del sitio, como carrusel, búsqueda, filtros, carrito y recibo.
- **Google Fonts:** recursos tipográficos externos.
- **YouTube y recursos de imágenes externos:** contenido audiovisual e imágenes enlazadas desde Internet.

## 6. Estándares de codificación

Para mantener el código organizado y facilitar su mantenimiento, se establecen los siguientes estándares:

1. Utilizar HTML5 y mantener una estructura clara del documento.
2. Escribir nombres de funciones y variables que describan su propósito.
3. Mantener una indentación consistente para facilitar la lectura.
4. Utilizar identificadores (`id`) únicos y descriptivos para los elementos que controla JavaScript.
5. Organizar el código por secciones y utilizar comentarios cuando ayuden a comprender una función.
6. Mantener los textos de la interfaz en español y revisar su ortografía.
7. Evitar duplicar funciones o bloques de código cuando se pueda reutilizar una función existente.
8. Comprobar que los botones, formularios, filtros y controles respondan correctamente.
9. Revisar que las imágenes, fuentes y demás recursos externos tengan enlaces válidos.
10. Registrar los cambios importantes en GitHub mediante commits con mensajes claros.

## 8. Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador web.
4. Para trabajar con un servidor local, se puede utilizar una extensión como Live Server en Visual Studio Code.

Se recomienda tener conexión a Internet porque algunos estilos, fuentes, imágenes y contenidos audiovisuales se cargan desde servicios externos.

## 10. Alcance, limitaciones y seguridad

- El inicio de sesión es demostrativo y funciona dentro del navegador; no verifica cuentas mediante un servidor.
- El carrito utiliza almacenamiento local del navegador.
- El proyecto no muestra una conexión a una base de datos ni a una pasarela de pago real.
- El recibo incluido en el repositorio es un ejemplo académico y no es un comprobante fiscal.
- Los recursos alojados en sitios externos pueden no mostrarse si no hay conexión a Internet o si el enlace deja de estar disponible.
- No se deben ingresar contraseñas reales ni datos personales sensibles en esta demostración.
- La información de productos, precios y contenido relacionado con salud debe ser revisada por personas responsables antes de cualquier uso comercial.
